Monthly memories media folders

Path format
public/memories/months/YYYY-MM/

Examples
public/memories/months/2024-11/
public/memories/months/2025-07/
public/memories/months/2026-01/

Naming convention inside each month folder
- image-1.jpg (or .jpeg/.png/.webp)
- image-2.jpg
- image-3.jpg
- vid-1.mp4 (or .webm/.mov)
- vid-2.mp4

How it works in the app
1. Open Memories.
2. Click a month in FlowingMenu.
3. You are taken to that month gallery view.
4. Media is shown in Card Swap UI.
5. Use Back To Months to choose another month.
